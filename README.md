The goal of OS_course_Fri_exercise is to explain the steps I have followed to complete the final exercise in the Open Science course held in Finse 19-23 2026. Also, I am using a quarto document for the first time :)

I will download occurrence data of collared pika (*Ochotona collaris*) from GBIF. There are >1,600 observations dating back to 1880! 

The dataset should be cited as: GBIF.org (21 October 2026) GBIF Occurrence Download https://doi.org/10.15468/dl.uma5wm 

In the script I load the dataset, clean it a bit and plot a figure on the number of observations over time in Canada and the United States.
